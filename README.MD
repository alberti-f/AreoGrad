# AreoGrad Project (WIP)

This Snakemake workflow computes parcel-wise cortical surface area and resting-state FC gradients for each subject, aligns gradients to a group reference, and evaluates whether gradient variability is associated with regional surface area using PLS regression with K-fold cross validation and with permutation tests.
